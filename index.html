ABOUT PROJECT

Fast, Semantic and Accessible

This project focuses on improving webpage performance while making the interface easier to use for people with different abilities.

Semantic HTML, optimized images, accessible forms, keyboard navigation, responsive layouts and clear color contrast are used throughout the website.
